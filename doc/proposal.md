## 1. 项目背景与目标

工厂生产中，需要将定长的原材料（钢管、槽钢、角钢等型钢）切割成不同长度的零件。
人工排料费时费力且浪费严重。本软件通过优化算法自动计算切割方案，**最大限度减少废料、
提高材料利用率**，并将结果以示意图和报表形式输出，供生产管理人员直接使用。

### 1.1 用户画像
- **使用者**：工厂生产管理人员（非技术人员，不熟悉命令行）。
- **使用方式**：在 Windows 电脑上双击打开软件，录入或导入零件清单，一键计算，
  查看/导出切割方案，交给车间执行。

### 1.2 术语说明（供使用者参考）

| 术语 | 含义 |
|---|---|
| 原料 / 母材 | 整根的待切割材料，如一根 6 米的钢管 |
| 零件 / 坯料 | 需要从原料上切下来的目标件，如 2 米管段 ×5 根 |
| 锯缝 / 刀口损耗 | 锯片厚度造成的材料损失，每切一刀损失若干毫米 |
| 余料 / 料头 | 一根原料切完零件后剩下的部分 |
| 废料 | 太短无法再利用、只能丢弃的余料 |
| 利用率 | 零件总长度 ÷ 投入原料总长度 × 100% |
| 切割方案 | 每根原料上各零件的排列方式及数量汇总 |

## 2. 业务范围与约束

1. **材料类型**：钢管、槽钢、角钢等一维条形材料。
2. **单材料计算**：每次计算只针对一种材料（如本次算钢管、下次算槽钢），
   不同材料不混切。
3. **单一定长原料**：工厂备有多种长度的原料，但**一次计算只使用一种原料长度**，
   由使用者在计算前指定。
4. **规模**：单次计算的零件可达**上千根**（长度种类不等），算法须在数秒内出结果。
5. **锯缝损耗**：必须计入，损耗宽度（毫米）可由使用者设置。
6. 暂无其他特殊工艺约束（无优先订单、无每根原料零件种类限制、无夹头预留）。
   后续如有需要以迭代方式加入。

## 3. 功能需求

### 3.1 数据输入（两种方式都要）

| 编号 | 功能 | 说明 |
|---|---|---|
| F1.1 | 界面手工录入 | 表格中逐行填写：零件长度（mm）、数量；可增删改行 |
| F1.2 | Excel 导入 | 从 .xlsx 文件导入零件清单（列：长度、数量）；提供模板下载；导入时校验数据并提示错误行 |
| F1.3 | 参数设置 | 原料长度（mm）、锯缝损耗（mm）、材料名称（如"Φ50钢管"，仅作报表标注用） |
| F1.4 | 数据校验 | 零件长度+锯缝 > 原料长度 时给出醒目警告；长度/数量必须为正值 |

### 3.2 优化计算

| 编号 | 功能 | 说明 |
|---|---|---|
| F2.1 | 一键优化 | 以**废料最少**为目标计算切割方案 |
| F2.2 | 利用率统计 | 显示：投入原料根数、零件总长度、原料总长度、**材料利用率%**、废料总长、平均每根余料 |
| F2.3 | 双模式求解 | 默认快速模式（启发式，千级零件秒出结果）；可选精确模式（数学规划，求最优解，耗时较长时显示进度并可取消） |
| F2.4 | 合法性保证 | 每根原料的切割方案满足：各零件长度 + 锯缝总和 ≤ 原料长度 |

### 3.3 结果展示与输出（四者都要）

| 编号 | 功能 | 说明 |
|---|---|---|
| F3.1 | 切割示意图 | 按比例横向条形图展示每种切割方式：原料全长、各零件段（标注长度）、余料段（灰色标注）；相同切法的原料合并显示"×N 根" |
| F3.2 | 方案表格 | 汇总表：方案编号、各零件长度与数量、余料、使用根数；以及零件明细核对表（需求 vs 实际切出数量） |
| F3.3 | 导出 Excel | 方案汇总表 + 零件核对表导出为 .xlsx |
| F3.4 | 导出/打印 PDF | 生成含示意图、参数、利用率、方案明细的 PDF 报告，可直接打印交车间 |

### 3.4 易用性

| 编号 | 功能 | 说明 |
|---|---|---|
| F4.1 | 打包分发 | 打包为 Windows 可执行程序（exe），免安装 Python，直接发给管理人员使用 |
| F4.2 | 参数记忆 | 上次使用的原料长度、锯缝等参数自动保存，下次启动恢复 |
| F4.3 | 错误提示 | 所有输入错误用中文弹窗说明原因及修改方法 |
| F4.4 | 中英文双语 | 界面支持中文/English切换（概要设计阶段确认新增） |

> 概要设计阶段确认裁剪：不做工程文件保存/打开（以Excel导入代替）；不做计算历史记录（用户自管导出文件）。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 1000 根零件规模，快速模式 ≤ 10 秒出结果 |
| 可靠性 | 计算结果必须通过合法性自检（总长不超原料、零件数量不少切） |
| 易用性 | 非技术人员无需培训即可完成"导入→计算→导出报告"全流程 |
| 可维护性 | 代码模块化：算法 / GUI / 导入导出 三层分离，便于后续加功能（如余料再利用、多材料混算） |
| 兼容性 | Windows 10/11，64 位 |

## 5. 技术方案

| 模块 | 选型 | 理由 |
|---|---|---|
| 语言 / 工程 | Python 3.11+，uv 管理 | 已确定 |
| GUI | PySide6 | 桌面软件；表格录入、绘图能力成熟；可打 exe |
| 优化算法 | ① 启发式（改进 FFD/最佳适配 + 局部搜索）② OR-Tools CP-SAT 精确求解 | 千级规模双模式，速度与最优兼得 |
| Excel 读写 | openpyxl / pandas | 导入料单、导出方案 |
| PDF 报告 | reportlab（或 matplotlib 出图 + 排版） | 中文报表与示意图 |
| 示意图绘制 | PySide6 自绘（QWidget/QGraphicsView） | 界面内嵌按比例切割图 |
| 打包 | PyInstaller | 生成单 exe 分发 |
